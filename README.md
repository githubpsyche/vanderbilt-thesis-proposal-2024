# Submitted Vanderbilt thesis proposal (September 2024)

A Quarto **manuscript** edition of Jordan Gunn's full submitted proposal, *Repetition, similarity, context: Clarifying how feature overlap across experience organizes memory search in free recall*.

- Website: https://githubpsyche.github.io/vanderbilt-thesis-proposal-2024/
- Original PDF: [Jordan_Gunn_Proposal.pdf](Jordan_Gunn_Proposal.pdf) (165 pages).
- Separate February sketch: https://githubpsyche.github.io/narrative-memory-proposal/

The proposal contains its overview and three chapters, coauthored with Sean Polyn: instance-based retrieved context; memory for repeated experience; and similarity versus repetition.

This archival edition preserves the proposal's scientific wording, plans, and preliminary claims. It is not the completed dissertation. The original PDF is the authoritative submitted artifact. For HTML, headings, figure and equation labels, and navigation have been adapted, and the chapter bibliographies consolidated. Original figures and parameter tables are included; no simulations are rerun.

## Build

Built with Quarto 1.8.27. Run `quarto render` to render the manuscript into `docs/`. GitHub Pages serves `main:/docs`.
